Terminal Paste Bin

A clipboard you can address.

Keep commands, URLs, IDs, and multiline text in persistent bins. Select a slot with one number, then read or write the system clipboard without leaving the terminal.

View on GitHub Install

Interface

Ten slots per bin, one keystroke each.

Features

Each bin is intentionally limited to ten slots.

  1. 01

    Ten direct-access slots

    Slots map to 1 through 9, then 0. Values can contain Unicode and multiple lines.

  2. 02

    Named or directory bins

    Run tpb myapp for a bin you can open from anywhere, or tpb with no argument for the current directory.

  3. 03

    Clipboard in and out

    Press w to save the system clipboard into the selected slot, or r to copy it back.

  4. 04

    Local JSON storage

    File locking and atomic writes. No account, daemon, sync service, or network calls.

Install

Requires Go 1.26.6 or newer. Clipboard support comes from pbcopy on macOS, wl-clipboard on Wayland, or xclip and xsel on X11.

Ten slots. No service attached.
