Live interfaces from plain HTML and JSON.

A tiny browser library that binds JSON responses to the DOM with declarative attributes. Built for dashboards, status views, and internal tools that should stay small.

Principles

Small enough to understand at a glance.

  1. 01

    HTML stays primary

    The page remains normal markup. ElectricHTML adds a binding vocabulary instead of replacing the authoring model.

  2. 02

    JSON is the contract

    A single response can drive headlines, status values, metrics, lists, and simple user actions.

  3. 03

    Useful before a full SPA

    There is a wide middle ground between static HTML and a large app shell. ElectricHTML is aimed squarely at it.

For the pages that want live data, not a giant app shell.
