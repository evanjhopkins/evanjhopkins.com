RunBinder

Keep the schedule with the code.

Define shell commands and schedules in YAML, commit them with your project, and run them through one local service backed by SQLite.

View on GitHub Install

Terminal

One binary, one local service, and no system cron to configure.

How it works

Registration stores a validated snapshot. Source edits show up as drift but do not change a running schedule until you update it.

  1. 01

    Define

    Create one small YAML file in your project. It stays readable in review and travels with the code it runs.

  2. 02

    Register

    RunBinder validates the file, resolves the working directory, and stores the snapshot under a namespace you can use from anywhere.

  3. 03

    Schedule

    Start one background service. It handles due schedules with bounded concurrency, overlap protection, and a misfire grace period.

  4. 04

    Operate

    Check the YAML state, run a task now, inspect its output, or pause it. Commands work from any directory once the task is registered.

Install

Go 1.24 or newer. Cron expressions, fixed times, and daily intervals are evaluated per task in its own IANA time zone.

A scheduler with a deliberately small footprint.
