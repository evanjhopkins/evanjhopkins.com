# evanjhopkins.com

Personal portfolio site for Evan Hopkins, live at [evanjhopkins.com](https://evanjhopkins.com).

Static HTML, CSS, and JavaScript with no build step, published via GitHub Pages from `main`.

## Structure

- `index.html`: home page
- `projects/`: project pages (ElectricHTML, RunBinder, Terminal Paste Bin)
- `assets/`: shared styles and theme toggle script

## Local preview

```sh
python3 -m http.server
```
